# v0.2.0

## 亮点

- 立起视觉基线：选定 IBM Carbon Design System 作为设计规范来源，Element Plus 正式接入并按 Carbon token 覆盖主题变量，界面不再依赖散落的硬编码色值。

## 新增

- 设计规范 [`DESIGN.md`](../DESIGN.md)：面向编码 agent 的设计系统说明，含色板角色、字体层级、组件样式、布局与间距、层级与阴影、交互状态、响应式与 Do / Don't，并给出到 Element Plus 变量的落地映射。
- 设计系统决策记录 [`docs/superpowers/specs/2026-10-10-jimu-portal-design-system.md`](../superpowers/specs/2026-10-10-jimu-portal-design-system.md)：选型理由与被否决候选、Carbon 到 Element Plus 的 token 映射、`ui-ux-pro-max` 技能的用法边界与安装说明。
- Element Plus 接入：`src/main.ts` 引入其样式并注册插件，样式顺序为 Element Plus 先、本项目 token 后。
- 设计 token 层：`src/styles/main.css` 收拢原先散落的 9 个色值为具名 `--jp-*` 语义 token，并覆盖 Element Plus 的 `--el-*` 主色、语义色及其派生色阶。
- E2E 校验 `e2e/design-tokens.spec.ts`：断言 token 覆盖生效，并同时断言 Element Plus 自有变量仍存在，以区分「覆盖成功」与「样式未加载」。
- [`AGENTS.md`](../AGENTS.md) 新增「设计系统」章节，固定 token 来源、样式引入顺序、派生色阶重算与 UI/UX 规则检索的边界。
- 认证与账号安全基础设施：`openapi-fetch` 传输层与统一信封解包、内存访问令牌 + `sessionStorage` 刷新令牌的会话层、单飞刷新与 401 重放、路由会话守卫，以及 `AuthLayout` / `PortalLayout` 两套布局；登录页按后端错误码逐步揭示图形验证码与 TOTP 字段。

## 变更

- 主色由青色 `#0f766e` 改为 Carbon 蓝 `#0f62fe`，品牌名、导航 hover、区块标签与按钮边框四处随之变化；中性色一并对齐 Carbon 色板。
- 空间与圆角：控件圆角统一为 4px，间距沿用 4px 网格。
- 依赖例行更新：`vitest` 4 → 5、`jsdom` 29 → 30、`@tanstack/vue-query`、`@vue/test-utils`、`prettier`、`eslint` 及两个 eslint 插件。
- CI：dependabot 的版本日志豁免改为按 PR 作者判定，避免维护者执行 update-branch 后豁免失效。

## 修复

- 修复维护者在 dependabot PR 上点 Update branch 后 `Policy` job 误判的问题（#7）。

## 验证

- `pnpm run check` 通过（契约同步、格式、lint、类型、单测与构建）。
- `pnpm run test:e2e` 通过（chromium）：应用外壳渲染、设计 token 覆盖，以及登录重定向与回跳、TOTP 字段揭示、凭据被拒提示。
- 覆盖有效性按「写入前先观察失败」验证：新增用例在接入前失败（`.brand` 实测为 `rgb(15, 118, 110)`），接入后通过。
- 构建产物层叠顺序单独校验：Element Plus 默认值位于打包 CSS 前部，本项目覆盖位于尾部，确认生产构建下覆盖仍然生效。
- 派生色阶按 Element Plus 的 `mix()` 规则复算全部默认值并逐一比对，确认取值方式与上游一致。

## 说明

- Element Plus 当前为全量引入（主包约 1MB / gzip 325KB），构建会提示 chunk 超过 500KB。全量引入是当时的取舍：按需导入需配合组件自动导入插件，而彼时尚未有组件，会使 `--el-*` 变量不存在、覆盖无从验证。登录页落地后组件已经存在，上述顾虑不再成立，按需导入可作为后续的独立优化方向。
- IBM Plex Sans 尚未随包引入，仅在系统已安装时生效；中文回落（PingFang SC / Microsoft YaHei）已就位。引入字体文件（尤其中文子集）体积可观，属独立决策。
- `--el-color-info` 保留 Element Plus 默认的 `#909399`，未按 Carbon 的 `semantic-info` 映射为主色蓝，以维持 `info` 的中性角色。
- Element Plus 表格类中性色变量（如 `--el-table-border-color`）尚未映射，待列表页落地时再处理。
- 设计系统当前只覆盖应用外壳与主题变量；除登录页外，尚无业务页面使用 Element Plus 组件。
- 后端不提供 `/auth/me` 类端点，也不返回权限点，因此本期只按登录状态守卫，不做权限驱动的路由、导航与按钮判定。
- 契约响应体没有 schema，前端在 `src/shared/api/types.ts` 维护载荷视图模型，后端字段变化不会触发前端类型报错。
- 访问令牌驻留内存、刷新令牌存于 `sessionStorage`：关闭标签页需重新登录。这是后端不支持 HttpOnly Cookie 前提下的折中。
- 本期未交付：账号安全四个子页（计划二）与注册、找回 / 重置密码（计划三）尚未开始；v0.2.0 只交付计划一，即认证基础设施与登录页。

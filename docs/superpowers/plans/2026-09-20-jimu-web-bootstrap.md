# Jimu Web Bootstrap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task with review checkpoints.

**Goal:** Initialize the independent `jimu-web` repository with project guidance, a minimal Vue 3 application, and reproducible CLI quality checks for formatting, linting, type checking, tests, API type generation, and production builds.

**Architecture:** Keep `jimu-web` independent from the Go backend repository. Use the standard Vue 3 + TypeScript + Vite application structure, with router, Pinia, TanStack Vue Query, Element Plus, and OpenAPI types available for later feature work. Keep the first runtime page as a small authenticated-portal shell placeholder; do not implement a business domain.

**Tech Stack:** Vue 3, TypeScript, Vite, Vue Router, Pinia, TanStack Vue Query, Element Plus, `@lucide/vue`, Vitest, Vue Test Utils, Playwright, ESLint, Prettier, `openapi-typescript`, pnpm 11.23.0.

## Global Constraints

- Repository name is `jimu-web`; product name is `Jimu Portal`.
- The backend repository at `../jimu` (relative to this repository root) is read-only for this task.
- Do not commit, push, or create a pull request unless the user explicitly requests it.
- Keep the business workspace as a shell; do not invent order, inventory, project, or content APIs.
- Use the exact `pnpm@11.23.0` version declared by `packageManager` and commit the generated `pnpm-lock.yaml` when the repository is later versioned.
- All user-facing project documentation is written in Chinese; code identifiers and pnpm script names stay in English.
- Every implementation behavior added after scaffolding must have a focused test written before the production behavior.

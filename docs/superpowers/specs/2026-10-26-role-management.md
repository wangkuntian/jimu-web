# 平台角色管理与权限分配

## 背景

后端 `jimu@78e22be43761ce3a67dea0ec05b75ab6fcba9323` 补齐角色管理契约：

- 角色列表支持 `tenant_id`、`keyword`、`status` 筛选。
- 创建角色支持平台管理员指定 `tenant_id`。
- `PUT /roles/{id}` 支持修改 `status`，`DELETE /roles/{id}` 表示停用。
- 新增 `GET /roles/{id}/permissions`，权限回显不再依赖角色详情。
- 权限 ID 改为字符串，`permission_ids` 支持空数组清空权限。
- 角色与权限管理端点仅平台管理员可访问。

## 页面范围

`/admin/roles` 首版提供：

- 角色列表：名称、说明、所属租户、状态、创建时间。
- 筛选：租户、角色名称、状态。
- 新建角色：必须选择所属租户。
- 编辑角色：名称、说明、状态；租户不可修改。
- 停用角色：二次确认，停用后可通过编辑重新启用。
- 分配权限：读取当前权限，按资源分组展示全部可分配权限，整体替换保存。

用户、租户和角色页继续共用 `ManagementPage.vue` 的页头、筛选卡片、状态、表格和分页骨架。

## 权限边界

- 导航和页面准入使用 `GET /api/v1/roles`。
- 新建、编辑、停用和权限分配分别检查各自请求路径。
- 权限按钮还要求具备 `GET /api/v1/permissions`、`GET/POST /api/v1/roles/*/permissions`。
- 平台管理员范围由后端判定；前端不根据角色名称推断权限。
- 权限目录是全局资源，不携带租户参数。

## 交互

- 新建和编辑使用 480px 右侧抽屉。
- 权限分配使用 560px 右侧抽屉，窄屏占满视口。
- 权限列表支持名称、资源、动作搜索。
- 每个资源分组支持全选；顶部显示已选数量。
- 保存前必须成功读取当前权限和权限目录，避免以空集合误覆盖。
- 清空全部勾选代表移除该角色的全部权限。

## 测试

- `role-params.spec.ts`：空筛选省略、`status=0`、租户和关键字透传。
- `roles-api.spec.ts`：分页、字符串 ID、创建、更新、停用、权限目录分页、当前权限和整体替换。
- `roles-view.spec.ts`：共享骨架、筛选、创建、编辑、停用、权限回显与保存、细粒度权限隐藏。
- `e2e/roles.spec.ts`：真实浏览器中的角色页、导航、权限抽屉和保存载荷。

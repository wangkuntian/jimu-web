# Jimu Hub 登录后导航框架

日期：2026-10-22

## 决策

- 登录后页面使用固定侧边栏作为主导航，不再在顶部重复展示同级页面入口。
- 布局与导航复用 Element Plus：`el-container`、`el-aside`、`el-header`、`el-main`、`el-menu`、`el-scrollbar`、`el-button`、`el-avatar`；只通过 token 覆盖视觉，不另造基础组件。
- 顶部工具栏只展示侧栏开关和当前页面标题；当前用户与角色收进侧边栏账户区。点击头像打开账户菜单，菜单提供工作概览、业务工作区、账号安全和退出登录。
- 工作概览与业务工作区始终可见；账号安全作为账户入口；租户管理只在具备 `GET /api/v1/tenants` 权限时显示。
- 页面增加“跳到主要内容”入口，所有导航和目标区域保留可见键盘焦点。

## 响应式

- 宽屏默认显示 232px 完整侧边栏，可通过工具栏按钮收起。
- 1023px 以下默认折叠为 72px 图标轨道，点击工具栏按钮可展开为完整侧边栏。
- 展开侧栏导致内容容器变窄时，页面内容通过容器查询自动切换为单列。
- 640px 以下侧边栏转为横向导航，触控目标不小于 44px。

## 动效

- 侧栏折叠完全使用 `el-menu` 原生 `collapse-transition`。
- 项目层不额外实现页面、卡片或侧栏宽度动画。

## 数据边界

导航角色用于展示，权限判定只读取服务端下发的 `permissions`；不根据角色名称推导权限，不新增后端请求。

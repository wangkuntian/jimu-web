# Jimu Hub 品牌命名与认证页调整

日期：2026-10-22

## 决策

- 产品显示名由 `Jimu Portal` 更新为 `Jimu Hub`。
- 仓库名继续保持 `jimu-web`，后端仓库继续保持 `jimu`，应用路由 `/portal` 不变。
- 发布静态资源包由 `jimu-portal-<tag>.tar.gz` 更新为 `jimu-hub-<tag>.tar.gz`。
- 登录页与注册页使用同一品牌区，只保留 Logo、产品名和一条品牌主张；不再展示品牌区辅助说明、页脚英文或编号能力清单。

## 原因

`Hub` 更直接表达统一入口和连接多类工作空间的定位。认证页需要让用户快速完成登录或注册，品牌文案不应与主任务争夺注意力。

## 兼容说明

带日期的既有设计、计划与发布文档保留当时的 `Jimu Portal` 命名，作为历史决策记录，不回写。
